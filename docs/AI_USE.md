# Synthetic Intelligence (SI) Use Disclosure

This document records the use of Synthetic Intelligence (SI) in **FieldShift Optimizer** in accordance with the official NASA Space Apps Challenge 2026 rules (`docs/HACKATHON_RULES.md`).

---

## 1. Origin of the Idea (Human-Originated)

- **Official Rule Compliance:** SI was **not** used to generate the idea of how to solve the challenge.
- The problem framing, decision-support concept (comparing current rotation vs. average-climate optimization vs. minimax regret under climate uncertainty in Rio Verde, GO), scope constraints, and non-leaky retrospective evaluation design were defined by the human team (`docs/DECISIONS.md`, `docs/EVALUATION_PROTOCOL.md`).

---

## 2. Descriptive Disclosure (Code, Data, and Documentation)

- **Code & Tests:** OpenBot agents powered by **Claude models** assisted with software implementation, refactoring, unit/leakage test authoring, and container configuration under human supervision and frozen technical specifications (`docs/DECISIONS.md`, `docs/CONTRACT.md`). Code modules assisted by SI carry the header `# AI-assisted (OpenBot agent)` as specified in `docs/CONTRACT.md`. All code and test outputs were verified by `pytest -q` (`170 passed in 17.53s`) and `ruff check .` (`All checks passed!`) in the development container.
- **Documentation:** OpenBot agents (Claude models) assisted in drafting and structuring English technical documentation (`README.md`, `docs/REFERENCES.md`, `docs/LIMITATIONS.md`, `docs/AI_USE.md`, `docs/SUBMISSION.md`), strictly grounded in verified repository artifacts and `reports/`.
- **Data Values:** **No climate or agronomic data values were generated by SI.** All climate records come directly from the versioned NASA POWER Daily Point API snapshot (`data/snapshots/power-daily-2.10.3-lat-18_lon-50.625-46c276253b44/manifest.json`), and all agronomic constraints come from official MAPA/ZARC tables, Agrodefesa regulations, and cited Embrapa publications (`docs/REFERENCES.md`).
